# Todo Breakdown Prompt

Convert this issue into actionable task items.

## Guidelines

Break the issue into discrete, completable tasks:
- Each task should be independently achievable
- Tasks should be specific and measurable
- Order tasks by dependency (what must come first?)
- Include both technical and non-technical tasks

## Output Format

Add a checklist comment:

```markdown
## Task Breakdown

### Research & Planning
- [ ] Task 1: [specific action]
- [ ] Task 2: [specific action]

### Implementation
- [ ] Task 3: [specific action]
- [ ] Task 4: [specific action]

### Validation
- [ ] Task 5: [specific action]

### Documentation
- [ ] Task 6: [specific action]

---
*Generated by triage system. Edit as needed.*
```

## Task Writing Tips

Good tasks:
- "Research API options for European grid data" ✓
- "Create database schema for site metadata" ✓
- "Write integration test for triage workflow" ✓

Bad tasks:
- "Do research" ✗ (too vague)
- "Implement feature" ✗ (too broad)
- "Fix stuff" ✗ (not specific)

## After Breakdown

Update the issue:
1. Add checklist comment
2. Apply label `status/tasked`
3. Optionally create sub-issues for large tasks
